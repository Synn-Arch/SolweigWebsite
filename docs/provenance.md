# Provenance

The behavioral reference is `nvnsudharsan/SOLWEIG-GPU` at commit
`0d7fe742abeeddd890dd58fc76ed7f78bd47faec`. The local reference checkout is
`.upstream/SOLWEIG-GPU`; it is excluded from candidate packaging and Git.
`reports/source_manifest.json` records SHA256 for every tracked source file.
`reports/contract_snapshot.json` records static signatures and CLI declarations;
it does not establish executable compatibility.

The reference runs in `.venv-oracle` (Python 3.11), with upstream installed from
that checkout. It never imports candidate code. `tools/run_reference.py` checks
the commit, tracked source changes, and installed Python file hashes before the
workflow. Each run records its installed dependencies and hardware/software
context. Source has not been patched. Installing upstream generated changes to
its tracked egg-info; these build metadata changes were restored before runs.

The host is macOS ARM64. CUDA is unavailable; CUDA equivalence is not passed.
Inputs are generated by `tools/generate_fixtures.py`, independently of any
candidate implementation. Generated inputs are not upstream reference outputs.

Upstream Python sources carry GPL-3.0-or-later notices, while setup metadata says
GPL-3.0-only. Preserve original notices in future translated files; the metadata
discrepancy remains documented rather than silently changing attribution.

## Reproduce initial characterization

```sh
git clone https://github.com/nvnsudharsan/SOLWEIG-GPU.git .upstream/SOLWEIG-GPU
git -C .upstream/SOLWEIG-GPU checkout --detach 0d7fe742abeeddd890dd58fc76ed7f78bd47faec
uv venv --python 3.11 .venv-oracle
uv pip install --python .venv-oracle/bin/python '.upstream/SOLWEIG-GPU[test]' 'GDAL==3.13.3' psutil
git -C .upstream/SOLWEIG-GPU restore solweig_gpu.egg-info
python3 tools/snapshot_upstream.py --upstream .upstream/SOLWEIG-GPU --reports reports
.venv-oracle/bin/python tools/generate_fixtures.py
.venv-oracle/bin/python tools/run_reference.py --fixture tests/fixtures/generated/own_met_small --kwargs reports/initial_kwargs.json --run reports/runs/initial_cpu
```

GDAL Python bindings require matching native GDAL; this host has Homebrew GDAL
3.13.3. The initial command fails because upstream imports Numba but does not
declare it. Preserve that failure; install Numba and use a **new** run directory
for the dependency-complete attempt. The harness rejects existing run folders.
