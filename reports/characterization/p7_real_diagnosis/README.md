## Remaining sparse and vegetation Kdown boundary diagnosis

The lead's expanded gate exposed Kdown-only failures at band15, sparse [250,40] (.05998993 W/m²) and vegetation-rich [118,62] (.05970764 W/m²). Both traces locate the cause before timestep0: svfveg differs by one float32 ULP, while svf at the failing pixel is exact. Original `svf + svfveg - 1` is 1.1920929e-7, candidate is zero. This becomes original svfalfa1.5704510 versus candidate1.5707963 and original F_sh≈.9987 versus candidate≈.9999997. Replaying the candidate wedge on original wedge inputs reduces its maximum discrepancy to under2.9e-6, confirming the material divergence enters through geometry-derived svfalfa rather than chronological state.

Read-only annulus diagnosis found upstream scalar-left `torch.pi / (2*n)` executes reciprocal then multiplication, producing float32 .017453294; the candidate directly divides rounded float32 pi to produce .017453292. NumPy float32 sine also differs from the original scalar Torch CPU sine. Of180 actual patch-option2 weights, current candidate reproduces43 bitwise. Reciprocal-first plus NumPy sine reproduces143; reciprocal-first plus native C float32 sine or Numba float32 scalar sine reproduces174. Six residual one-ULP differences originate in Torch sine results at altitudes48,55,62, which are not bitwise identical to native C sinf on this host.

Using original visibility masks and upstream addition order at both failure pixels, reciprocal-first plus native scalar sine reconstructs svfveg, tiny positive tmp and svfalfa exactly as the original, while reciprocal-first plus NumPy sine retains the failure. This suggests the smallest repair is the native scalar weight calculation; six remaining weight differences must remain explicitly labeled and all frozen final gates must pass before accepting it. No clamp, threshold relaxation, fixed-table approximation or scientific correction is proposed. See `remaining_scene_diagnosis.json` and `svf_weights/boundary_pixel_reconstruction.json`.
