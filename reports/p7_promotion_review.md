# P7 promotion review — decision still open

The completed v4 matrix establishes full-workload benefit over the explicitly repaired P6 baseline on all six 256-square scenes. Across their four cache/thread groups, median ratios range from 2.781 to 4.515. These are not original-upstream speedups. All 140 pairs pass numerical/artifact/cache comparisons, and final source/evidence guards pass. Detailed data and hashes: `p7_completed_matrix_review.json`, `p7_pair_measurements.md`, and `characterization/p7_pairs_v4/`.

The startup-sensitive small case needs a qualified decision: three median ratios exceed one, while four-thread geometry-warm has median 0.986892 and range 0.912775–1.079209. This is a measured median regression with mixed individual trials, not an established improvement. The protocol uses a fresh JIT directory for every measured process even in geometry-warm runs; it cannot distinguish startup cost from steady-state execution. Separate complete warmed profiles now produce matching outputs, but retain roughly six seconds of compilation whose kernel/signature cause is still being investigated.

Peak process-tree RSS increases in the candidate's observed range on every scene. The largest recorded candidate maximum is 605,421,568 bytes, compared with 563,642,368 bytes for that scene's repaired baseline. All observed values remain below the frozen 12 GiB budget. These measurements do not show a P7 memory reduction; compiled decoder/classifier overhead must be acknowledged. The prior compact representation's memory benefit is separate historical evidence.

The source-level invariants and correctness reports support retaining the bounded decoder/classifier for review: no patch reduction or reassociation, lossless raw/categorical decoding, lock-protected mapped reads, deterministic local reductions, bounded block storage. No new default source change is made by this report. Formal promotion remains open pending the startup/crossover interpretation and explicit disposition of the remaining P7 experiment deliverables. Unimplemented horizon, hierarchy, moment-reassociation and Horner approaches are not completed experiments. A C++ backend remains unjustified without a residual bottleneck warranting its build/maintenance cost.

This review does not waive the four independent scientific failures or the original CUDA cold-path resource failure. P8 still requires the full original-default/tuned-CPU comparison matrix, platform packaging/CI, and final scope/evidence review.
